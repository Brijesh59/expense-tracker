🌕 Luma Onboarding — First 5 Minutes
🧭 Core Strategy
Show value immediately (not features)
Minimize thinking
Build momentum through small wins
Match Luma personality: calm, clear, human
🪜 Flow Overview
Welcome / Hook
Quick Intent (optional)
Set First Budget (guided)
Log First Expense (instant win)
First Insight (magic moment)
Soft Landing (dashboard)
🧩 1. Welcome Screen
🎯 Goal

Make user feel: “This is simple. I can do this.”

Copy

Headline:

“Understand where your money goes”

Subtext:

“No pressure. Just clarity.”

CTA:

“Get started”

Alternative (slightly warmer)

“Let’s make your spending a little clearer”

🧩 2. Intent (Optional, 1-tap)
🎯 Goal

Personalize tone lightly without friction

Question:

“What brings you here?”

Options (chips):
“Track my spending”
“Stay within budget”
“Just exploring”
Behavior:
Skippable
No branching complexity (v1)
🧩 3. Set First Budget (Critical)
🎯 Goal

Anchor the system → budgets = foundation

Screen Copy

Headline:

“Let’s set a simple budget”

Subtext:

“Start with one category — you can add more later”

Pre-filled Category (important)

👉 Default: Food / Dining

Budget Input Placeholder:

“₹5,000”

Helper Text:

“Most people start here”

CTA:

“Set budget”

Micro reassurance:

“You can change this anytime”

👉 Remove decision fatigue = faster activation

🧩 4. Log First Expense (MOST IMPORTANT STEP)
🎯 Goal

Create momentum + habit loop

Screen Copy

Headline:

“Now log your first expense”

Subtext:

“Just something you spent recently”

Pre-filled:
Category → Food (from previous step)
Date → Today
Amount Placeholder:

“₹200”

CTA:

“Save”

Microcopy:

“This takes a second”

👉 You’re removing thinking. Just action.

🧩 5. ✨ First Insight (MAGIC MOMENT)
🎯 Goal

User feels: “Oh… this is actually useful”

After saving expense:

Card appears:

“This uses 4% of your food budget”

Follow-up line:

“You’re off to a good start 👍”

👉 This is where Luma differentiates

Optional contextual (if amount large):

“This is a bigger spend — something to keep in mind”

🧩 6. Dashboard Soft Landing
🎯 Goal

Let user see progress immediately

Highlight animation:
Budget ring fills slightly
Category shows progress
Top Message:

“Here’s your month so far”

Subtext:

“You’ve logged your first expense”

Optional nudge:

“Try adding one more today”

🧩 7. Empty States (Post-Onboarding)
Transactions empty:

“Start by logging what you spend”

Budgets empty (if skipped):

“Set a budget to guide your spending”

⚡ Key UX Principles (IMPORTANT)
1. No multi-step forms

Everything = one screen, one action

2. Pre-fill aggressively
Category
Date
Sample amounts
3. Reduce thinking

Don’t ask:

“Which category?”

Instead:

Give default → let them change

4. Reward immediately

Insight after first action = dopamine

🧠 What user feels step-by-step
“This looks simple”
“Okay, I can try”
“That was easy”
“Oh, I get it now”
“Maybe I’ll keep using this”
🚫 What NOT to do
❌ No long onboarding carousel

Skip:

“Track your expenses”
“Visualize your data”
“Take control of finances”

👉 Nobody cares

❌ No account creation upfront

Let them:

use app first
sign up later (after value)
❌ No too many categories

Start with ONE

🏆 Activation Target

Within 2 minutes:

✅ 1 budget created
✅ 1 expense logged
✅ 1 insight shown

💡 Final Insight

Your onboarding should feel like:

“I already started using the app”

NOT:

“I finished setting up the app”
